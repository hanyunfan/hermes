# `imports/` — drop your Grok-generated JSON here

This template is a scaffold. To use it as a real project:

1. Copy the entire `template2/` directory to `projects/<your_project_id>/`.
2. Place your Grok-generated JSON files in this `imports/` directory:
   - `story.json`
   - `characters.json`
   - `scenes.json`
   - `shots.json`
3. Place character reference images under `imports/references/<character_id>/`.
4. Run `video-director validate-imports <project>` and follow the errors.

See the parent `template2/README.md` for the full setup walkthrough.
