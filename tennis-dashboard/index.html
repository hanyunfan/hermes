🔐 One-time login setup

UTR, USTA TennisLink, and Active Communities all gate their data behind login. We never store your password — instead, you log in once in a browser, and we save the resulting session cookies. Sessions typically last 60–90 days before re-auth is required.

  1. Install dependencies locally (only once): 
    pip install -r requirements.txt
playwright install chromium
  2. Copy .env.example to .env and fill in your HOME_* values.
  3. For each service, run a one-time login capture: 
    python scripts/capture_session.py utr
python scripts/capture_session.py usta
python scripts/capture_session.py anc
  4. Run the fetcher locally to populate data/tournaments.json: 
    python scripts/fetch_tournaments.py
  5. Commit the refreshed data file. GitHub Actions will refresh it daily at 6am Central thereafter.
⚠️ Court booking is intentionally conservative. The auto-booking script stages reservations but does NOT click Submit — that final confirmation stays with you. See scripts/book_court.py for details.
🛠️ CLI quick reference
# Refresh tournament data
python scripts/fetch_tournaments.py

# Browse available ANC slots in a real browser
python scripts/book_court.py --browse

# Plan a reservation (no real booking, just records it)
python scripts/book_court.py --date 2026-07-22 --time 17:00 --duration 60 --plan

# Attempt an actual booking (will pause before submit)
python scripts/book_court.py --date 2026-07-22 --time 17:00 --duration 60

# Geocode a ZIP (used internally for distance calculation)
python scripts/geocode_zip.py 78750
